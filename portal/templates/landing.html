What it checks

One toolkit for every kind of AI system

Each run produces a health score, a verdict (PASS, PASS WITH WARNINGS, NEEDS WORK or BLOCK), findings ranked by severity and a root-cause diagnosis.

{{ m.icon('cpu') }}

ML models

Performance beyond accuracy, calibration, overfitting, data leakage, drift, fairness (four-fifths rule, equal opportunity), robustness and proxy features.

{{ m.icon('sparkles') }}

LLM apps

Hallucination and grounding, safety and over-refusal, PII leaks, prompt injection and jailbreaks, counterfactual bias, JSON validity, latency and cost.

{{ m.icon('workflow') }}

Automations and agents

Task success, tool-call order, excessive agency, human-oversight bypass, fault tolerance and idempotency for tool-calling workflows.

{{ m.icon('shield') }}

Compliance

Control-by-control gap analysis for the EU AI Act, NIST AI RMF, GDPR, ISO/IEC 42001, the OWASP Top 10 for LLM apps and sector rules.

{{ m.icon('bolt') }}

Auto-fix, verified

Prioritised fixes are applied and the full suite is re-run. A fix is kept only if it actually improves the result.

{{ m.icon('key') }}

Bring your own key

Live LLM tests run on your Anthropic or OpenAI-compatible account. Deployed ML models can be tested through their HTTP endpoint.

How it works

From upload to verified fix in four steps

  1. Connect

    Upload a CSV or JSONL dataset, pick a demo, or point at an LLM provider or a deployed endpoint.

  2. Run the suite

    Performance, fairness, robustness, safety and security tests run in the background.

  3. Read the verdict

    Health score, findings by severity, compliance gaps and a root-cause diagnosis in one report.

  4. Fix and verify

    Apply auto-fixes, re-evaluate, and compare runs side by side before you ship.
